# AutoLoc-API
## Acteurs et cas d'utilisation (S 1)

### Client
- S'inscrire / se connecter
- Rechercher un véhicule disponible
- Réserver un véhicule
- Consulter/annuler ses réservations

### Agent d'agence
- Enregistrer une location
- Gérer le retour d'un véhicule
- Consulter le planning des véhicules

### Responsable d'agence
- Gérer le parc de véhicules (ajout/retrait)
- Superviser les agents
- Consulter les statistiques de l'agence

### Administrateur
- Gérer les comptes utilisateurs
- Gérer les agences (création/suppression)
- Superviser l'ensemble du système
